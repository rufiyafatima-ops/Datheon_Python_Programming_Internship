# Python Internship Projects

Three Python projects built for the internship programme. Each project lives in its own folder with its own README and run instructions.

| Task | Project | Folder | Main file |
|------|---------|--------|-----------|
| 2 | Stock Portfolio Performance Tracker | [task-2-portfolio-tracker](./task-2-portfolio-tracker) | `portfolio.py` |
| 3 | Automated File Organizer & Cleanup Utility | [task-3-file-organizer](./task-3-file-organizer) | `organizer.py` |
| 4 | Rule-Based Interactive Terminal Chatbot | [task-4-chatbot](./task-4-chatbot) | `chatbot.py` |

## Requirements
- Python 3.8 or newer
- No external libraries needed (`yfinance` is optional for live stock prices in Task 2)

## Quick start
```bash
git clone <this-repo-url>
cd <repo-folder>

python task-2-portfolio-tracker/portfolio.py --demo
python task-3-file-organizer/organizer.py ~/Downloads --dry-run
python task-4-chatbot/chatbot.py sample_faq.json
```
(Run Task 4 from inside its folder if the dataset path is not found.)
